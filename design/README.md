# Handoff: Печатня — конструктор игровых газет (desktop, Flet)

## Overview

Десктопное приложение для настольных и ролевых игр: мастер собирает выпуск вымышленной газеты — задаёт бренд издания, верстает полосы из блоков, пишет статьи, накладывает эффект состаренной бумаги и выгружает PNG/PDF для чата или печати.

Пакет описывает девять экранов: список проектов, карточка издания, пресеты оформления, шаблоны сетки, главный экран вёрстки с живым превью полосы, редактор статьи, панели типографики и бумаги, диалог экспорта, экран бренда издания.

Исходное ТЗ приложено: `ТЗ - newspaper_generator_tz.md`.

## About the Design Files

Файлы в этом пакете — **дизайн-референсы, сделанные в HTML**. Это прототипы, показывающие задуманный вид и поведение, а не продакшн-код для копирования.

Задача — **воспроизвести эти макеты в целевой среде проекта**, следуя её принятым паттернам. По ТЗ целевая среда — Python + Flet (desktop, Windows), рендер полосы через HTML/CSS-движок или собственный рисовальщик. Если среда ещё не выбрана — выбрать подходящую и реализовать там. HTML из пакета не встраивать как есть.

Важное следствие для Flet: то, что в макете сделано CSS-свойствами (`column-count`, `float`-буквица, `mix-blend-mode: multiply`, `repeating-linear-gradient`), в целевой среде надо решать иначе — см. раздел «Рендер полосы».

## Fidelity

**High-fidelity.** Точные цвета, шрифты, кегли, отступы и состояния. UI-хром воспроизводить по значениям из этого README; наборную полосу — по метрикам раздела «Полоса».

Не воспроизведён намеренно: анимации, наведение курсора, drag-and-drop в динамике, скролл-состояния.

### 09 · Бренд издания

Назначение: постоянная айдентика, наследуемая всеми выпусками издания. Правка бренда меняет шапки во всех номерах, вёрстка остаётся.

**Левая панель 256** — список брендов с наборными миниатюрами: Harbour Gazette (готический, активен), Evening Ledger (Bodoni Moda caps), Вечерний вестник (Old Standard TT), Голос дока (Oswald); пунктирная строка «＋ Новый бренд» 52 px; внизу заметка о наследовании.

**Центр:** заголовок панели «Логотип и применение», справа «масштаб по ширине полосы A3».
- Большая шапка на бумаге `#efe7d4`: служебная строка (VOL. VI · NO. 212 / PORT ARCADIA · WEDNESDAY, JUNE 12 / FIVE CENTS), логотип UnifrakturMaguntia 60 px, девиз в разрядку 0.28em между линейками 120 px, двойная линейка, рубрикатор через ромбы `✦`.
- Три карточки применения: шапка внутренней полосы; штамп (круг 52 px) + колонцифра; плашки рубрики (выворотка на `#15120e` и линейчатая).
- «Направления логотипа» — четыре карточки 88 px: Готический (активен; кириллица антиквой), Новая антиква (Bodoni Moda, разрядка 0.1em), Узкий гротеск (Oswald), В рамке (`2px solid` + PT Sans Narrow 0.2em).
- Нижний ряд: «Минимальный размер и охранное поле» — три версии логотипа (148 / 82 / 36 мм) в пунктирных рамках `1px dashed #b08a5e` с подписями; «Постоянные элементы» 300 px — выходные сведения и подпись редакции.

**Правая панель 340:** вкладки «Логотип | Рубрикатор | Краска». Поля: Название · латиница (в фокусе), Название · кириллица + заметка о подмене готики антиквой; селект гарнитуры логотипа; «Кегль логотипа, пт» 60, «Трекинг, ‰» 20, тумблеры «Надстрочная строка» (выкл.) и «Девиз под названием» (вкл.); поле «Девиз / Motto»; сегмент «Линейки под шапкой» — Одна / **Жирная + тонкая** / Орнамент; «Краска» — четыре свотча 26×26 (`#15120e` активен, `#1f2a44`, `#6b3226`, `#2a3a2c`) с подписью «одна краска на весь выпуск». Низ: «Дублировать бренд» + primary «Применить ко всем».

## Полоса (наборные метрики)

Лист A3-пропорций: **794 × 1123 px** при 96 dpi (в макете показан с `scale(0.74)`), поля **34 px по вертикали, 38 px по горизонтали** → полоса набора 718 × 1055.

Шапка первой полосы:
- Служебная строка: PT Sans Narrow 10 px, трекинг 0.14em, `#453b2e`, снизу `1px solid #6d6250`, отступ 4 px.
- Композиция логотипа — grid `112px 1fr 112px`, `gap 14`, padding `12/0/8`. Боковые боксы: `border-top/bottom 1px #15120e`, PT Sans Narrow 8.5/1.5, трекинг 0.08em, цифры 11 px. Центр: надстрочная строка Old Standard TT 13 px с трекингом **0.62em** (плюс `text-indent` на ту же величину, иначе строка уходит влево), под ней логотип Old Standard TT 700 **58 px**, трекинг 0.05em, `white-space: nowrap`.
  - Ограничение: min-content логотипа не должен превышать `718 − 112·2 − 14·2 = 466 px`, иначе grid распирает полосу. При более длинных названиях уменьшать кегль или боковые боксы.
- Девиз: Old Standard TT italic 12.5 px `#453b2e`, по центру, отступ снизу 9.
- Двойная линейка: `2.5px` + `1px` `#15120e` через 2.5 px.
- Рубрикатор: PT Sans Narrow 9 px, трекинг 0.2em, `gap 22`, ромбы `✦` цветом `#8d8271`, снизу `1px solid #15120e`.

Главная статья (блок `flex:1`):
- Рубрика: PT Sans Narrow 10 px, 0.2em, `#6b3226`, подчёркнута `1px #b8ae9b`.
- Заголовок: Old Standard TT 700 **38/1.04** `#15120e`.
- Лид: Old Standard TT italic 15/1.35 `#3a3227`, снизу линейка.
- Строка автора: центрированная PT Sans Narrow 9 px / 0.16em между двумя линейками `1px #cac2b0`.
- Текст: `column-count: 3`, `column-gap: 14`, `column-rule: 1px solid #cac2b0`, PT Serif **11.5/1.52** `#1c1812`, `text-align: justify`, `hyphens: auto`.
- Буквица: Old Standard TT 700 46 px, `line-height .82`, `float: left`, `padding: 3px 6px 0 0`; первые слова — капитель (`font-variant: small-caps`, трекинг 0.03em).
- Внутренние подзаголовки: PT Sans Narrow 700 10 px, 0.14em, отступы `7/0/3`.
- Фото: `break-inside: avoid`, полутон-плашка 96 px, подпись под линейкой `1px #15120e` — префикс «СНИМОКЪ.» PT Sans Narrow 700 8.5 px, далее PT Serif italic 9.5/1.4 `#3f372b`.
- Строка перехода: PT Sans Narrow 10 px, 0.1em, `#6b3226`, над ней линейка.

Боковая колонка 196 px (`border-left: 1px #15120e`, padding-left 14, `gap 10`): рамка «ПОГОДА НА СУТКИ»; блок «КУРСЫ И ЦЕНЫ» между линейками (строки `space-between` PT Serif 10.5/1.7); врезка-цитата Old Standard TT italic 700 14/1.3 + атрибуция; рамка «ОБЪЯВЛЕНIЕ» (`2px solid`); блок «ПАМЯТИ»; внизу полутон-плашка 64 px.

Нижняя лента: `border-top: 2.5px #15120e`, три материала `flex:1` с разделителями `1px #cac2b0`, у каждого рубрика PT Sans Narrow 8.5 px / 0.18em `#6b3226`, заголовок Old Standard TT 700 15/1.16, текст PT Serif 10.5/1.5 justify.

Колонцифра: `border-top: 1px #15120e`, PT Sans Narrow 8.5 px / 0.16em `#5a5145`, три поля `space-between` — издание и номер, «— 1 —», дата.

Общий приём: на контейнере полосы `text-shadow: 0 0 .45px rgba(20,16,12,.55)` — имитация растекания краски. При переносе в Flet заменить лёгким размытием или утолщением начертания.

## Рендер полосы (эффект бумаги)

Слой состаривания — оверлей поверх всей полосы с `mix-blend-mode: multiply` и `opacity = intensity/100 × 0.9`, где `intensity` — значение слайдера 0…100 (дефолт 55). Состав слоя, в порядке наложения:

1. Виньетка: `radial-gradient(70% 52% at 50% 46%, rgba(214,196,158,0) 0, rgba(178,150,104,.26) 74%, rgba(140,112,68,.46) 100%)`
2. Пятно в левом верхнем углу: `radial-gradient(26% 18% at 14% 12%, rgba(156,122,62,.3), transparent 72%)`
3. Пятно в правом нижнем: `radial-gradient(22% 16% at 88% 82%, rgba(140,106,54,.32), transparent 70%)`
4. Мелкое пятно: `radial-gradient(14% 9% at 68% 33%, rgba(132,98,46,.3), transparent 74%)`
5. Залом по центру: `linear-gradient(90deg, transparent 47.4%, rgba(120,94,52,.22) 49.6%, rgba(255,250,238,.3) 50%, rgba(120,94,52,.2) 50.4%, transparent 52.6%)`
6. Неравномерность оттиска: `repeating-linear-gradient(93deg, rgba(90,70,40,.06) 0 2px, transparent 2px 7px)`

Чекбоксы панели «Бумага» включают и выключают группы: «Желтизна и сепия» → 1, «Пятна и разводы» → 2–4, «Неравномерность печати» → 6, «Заломы и сгибы» → 5, «Зерно скана» → дополнительный шум (в макете не реализован).

Во Flet CSS-смешивание недоступно напрямую: слой собирать как изображение (PIL — градиенты + `ImageChops.multiply`) и накладывать поверх отрендеренной полосы, либо рендерить полосу в браузерном движке и накладывать оверлей там же. Экспорт обязан учитывать текущее значение слайдера.

## Interactions & Behavior

- **Список проектов:** двойной клик по карточке — открыть выпуск; «Новый выпуск» ведёт на 02 → 04 → 05.
- **Создание выпуска:** двухшаговый мастер; «Далее» активна при заполненном названии.
- **Выбор пресета и шаблона:** одиночный клик выделяет (рамка `#C05B42`), выбор применяется к текущей полосе и правится вручную далее.
- **Вёрстка:** статьи перетаскиваются из левого списка в блоки полосы; границы блоков тянутся мышью; выделенный блок получает outline + бейдж; двойной клик по блоку открывает 06.
- **Контроль вместимости:** при каждой пересборке считается заполнение блока. < 100 % — зелёный индикатор и процент; > 100 % — строка статьи и статус-бар подсвечиваются `#e08b73`, показывается остаток в знаках, предлагается блок «продолжение на стр. N».
- **Редактор статьи:** превью пересобирается по паузе в наборе (debounce ~400 мс), не на каждый символ. Ctrl+B / Ctrl+I — начертания.
- **Панели:** переключаются вкладками внутри правой колонки, полоса остаётся видимой; изменения применяются немедленно.
- **Слайдер состаривания:** непрерывное обновление превью; значение дублируется в статус-баре и в диалоге экспорта.
- **Экспорт:** рендер локальный, с прогрессом по полосам; имена файлов `<издание>-<номер>-p<N>.png`.
- **Бренд:** «Применить ко всем» перерисовывает шапки во всех выпусках издания, вёрстку не трогает; «Дублировать бренд» создаёт копию для нового издания.
- **Подмена шрифта:** если выбранная гарнитура не содержит кириллицы (готические), кириллическая строка набирается запасной антиквой; предупреждение показывается в панели бренда.

## State Management

- `projects[]` — список проектов (файл JSON + папка изображений рядом).
- `issue` — метаданные выпуска: название, слоган, номер, дата, цена, город, число полос, рамка шапки.
- `brand` — айдентика издания: названия в двух алфавитах, гарнитура логотипа, кегль, трекинг, девиз, тип линеек, рубрикатор, краска. Наследуется выпусками.
- `pages[]` → `blocks[]` — геометрия блоков в модульной сетке (колонка, строка, span), тип блока (статья / модуль / фото).
- `articles[]` — рубрика, заголовок, подзаголовок, автор, место и время, тело с разметкой, привязка к блоку, изображения.
- `stylePreset` + `typography` — гарнитуры и кегли (шапка, заголовки, текст, интерлиньяж).
- `paper` — вкл/выкл, интенсивность 0…100, флаги слоёв.
- `ui` — активная полоса, выделенный блок, активная вкладка панели, зум, видимость сетки/бумаги/границ.
- `fit` — вычисляемое: процент заполнения каждого блока и остаток в знаках; пересчитывается при правке текста, смене кегля, ширины блока и числа колонок.

Данных с сервера нет: всё локально, автосохранение проекта с отметкой времени в статус-баре.

## Assets

Изображений в макете нет. Фотографии заменены плейсхолдерами `repeating-linear-gradient(135deg,#cfc8b6 0 4px,#ddd6c6 4px 8px)` с подписью размера в миллиметрах. В приложении пользователь подставляет собственные файлы; в макете предполагается фильтр «Полутон / Сепия / Ч/Б».

Шрифты — Google Fonts: IBM Plex Sans, IBM Plex Mono, Old Standard TT, PT Serif, PT Sans Narrow, Oswald, UnifrakturMaguntia, Bodoni Moda. Для десктопной сборки положить в комплект локально (все SIL OFL). UnifrakturMaguntia и Bodoni Moda — без кириллицы.

## Files

- `Печатня - конструктор газет.dc.html` — все девять экранов в одном файле, в порядке 01…09.
- `support.js` — рантайм, нужен для открытия макета в браузере. Продакшн-кода не содержит.
- `ТЗ - newspaper_generator_tz.md` — исходное техническое задание (этапы MVP / v2 / v3, ограничения Flet).

Открывать макет: положить оба файла рядом и открыть `.dc.html` в браузере. Ползунок состаривания и показ колоночной сетки вынесены в параметры макета — их можно менять и смотреть, как перестраивается полоса.
