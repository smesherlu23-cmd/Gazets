# ТЗ: Конструктор игровых газет (десктоп, Flet)

## 1. Суть проекта

Десктопное приложение для Windows, в котором пользователь (мастер или игрок NRP/настольной ролевой) собирает выпуск «внутриигровой» газеты: пишет/вставляет тексты статей, расставляет их по макету полосы, оформляет заголовки, колонки, иллюстрации, врезки — и экспортирует готовый разворот как PDF и/или PNG для печати или отправки в чат группы.

Инструмент универсальный — не привязан к конкретному сеттингу. Пользователь сам определяет название издания, эпоху/стиль оформления, набор рубрик. Программа отвечает только за вёрстку и внешний вид; тексты статей пользователь пишет сам, никакой генерации контента не требуется.

Ключевой критерий качества — визуальная достоверность: результат должен выглядеть как отсканированная/сфотографированная настоящая газета, а не как аккуратный современный документ с текстом в рамках.

## 2. Платформа и стек

- Python 3.x + Flet — оболочка приложения, редактор, вся интерактивная UI-часть (панели, список статей, настройки, превью).
- Windows 10/11, локальное приложение, работает офлайн, без облачных зависимостей.

### Рекомендация по архитектуре рендеринга полосы

Сама газетная полоса (то, что видит и экспортирует пользователь) — это сложная типографика: многоколоночная вёрстка с перетеканием текста, выключка по ширине, буквица, переносы, разные кегли заголовков, подписи под фото, рамки объявлений. Реализовать это вручную на Flet-канвасе трудоёмко и ограниченно (Flet — обёртка над Flutter, у неё нет готового механизма CSS-подобной многоколоночной вёрстки).

Предлагаемый подход: Flet используется только для UI редактора (ввод текста, настройки, список статей, выбор шаблона), а сама полоса рендерится отдельным движком через HTML/CSS-шаблон (CSS `column-count` даёт многоколоночный реflow «из коробки») и превращается в PDF/PNG через headless-рендерer (например, WeasyPrint для PDF или headless-браузер для PNG). Превью в самом Flet-приложении может быть тем же HTML-рендером, встроенным как WebView/изображение.

Альтернатива — рисовать полосу напрямую средствами Flet (Canvas/Stack) без промежуточного HTML-слоя. Это проще с точки зрения единого стека, но заметно сложнее в реализации многоколоночного текста и качественной типографики. Решение по этому пункту стоит закрепить перед началом кодирования — прошу Claude Code явно предложить один из двух вариантов и обосновать выбор, если по ходу разработки выяснится, что один существенно проще другого.

## 3. Пользовательские сценарии

1. Создать новый выпуск: указать название издания, номер, дату, цену, слоган, выбрать стиль оформления.
2. Добавить статьи: заголовок, подзаголовок, автор/рубрика, основной текст, опционально фото/иллюстрация.
3. Разместить статьи на полосе: выбрать шаблон-сетку (например, «шапка на всю ширину + 3 колонки» или «врезка сбоку + основной блок»), перетащить/назначить статьи в блоки.
4. Настроить типографику: количество колонок в блоке, шрифт (набор пресетов под разные эпохи/стили), буквица у лид-абзаца, выравнивание.
5. Добавить дополнительные модули: объявления/реклама, погода, курсы валют или иной «служебный» блок, цитата-врезка, некролог, подпись под фото.
6. Включить эффект состаренности/износа бумаги (опционально, регулируемая интенсивность).
7. Посмотреть превью полосы в реальном времени.
8. Сохранить проект (для последующего редактирования) и экспортировать готовый результат в PDF и/или PNG.
9. Переиспользовать издание: создать новый номер того же издания на основе сохранённых настроек стиля/шапки.

## 4. Функциональные требования

### 4.1 Управление изданием и выпуском
- Создание/открытие/сохранение проекта газеты (файл проекта, формат JSON).
- Карточка издания: название, слоган/девиз, номер выпуска, дата, цена, город/место издания (все поля произвольный текст, без привязки к реальному миру).
- Список выпусков одного издания — быстрое создание нового номера с наследованием оформления.

### 4.2 Стили/темы оформления
- Набор готовых пресетов оформления (шрифты, толщина линеек, кегли заголовков, наличие декоративных элементов), например: «классическая пресса», «таблоид», «официальный вестник/бюллетень», «партийная агитка», «подпольный листок». Пресеты — стартовые наборы, пользователь может их менять вручную.
- Настройка вручную: гарнитура для заголовков и для основного текста (из установленных в системе + несколько встроенных), межколоночные линейки вкл/выкл, декоративная рамка шапки.

### 4.3 Макет полосы
- Библиотека шаблонов-сеток полосы (расположение блоков: шапка, главная статья, боковые колонки, врезки, нижний блок).
- Возможность вручную скорректировать пропорции блоков в пределах шаблона (перетаскивание границ).
- Поддержка нескольких страниц в одном выпуске (передняя полоса + внутренние развороты), с элементом «продолжение на стр. N».

### 4.4 Текст и типографика
- Ввод текста статьи (плейн-текст с минимальным форматированием: курсив, полужирный, буквица).
- Автоматическое перетекание текста по колонкам блока; если текст не помещается — визуальная индикация переполнения и/или автоматический перенос остатка блоком «продолжение на стр. N».
- Выключка по ширине (justify), перенос слов.
- Иерархия заголовков: набор пресетов размеров (главный заголовок полосы, заголовок статьи, подзаголовок, рубрика/шапка над заголовком).
- Подписи авторов, дата/место под заголовком статьи (по желанию).

### 4.5 Изображения
- Вставка изображений в блок (фото/иллюстрация/карта), обрезка и масштабирование под область блока.
- Подпись под изображением.
- Опциональный фильтр «под старую печать» для изображений (полутоновая/растровая имитация газетной печати, чёрно-белое или сепия).

### 4.6 Реализм и состаривание
- Регулируемый эффект старой бумаги: текстура, лёгкая желтизна/сепия, пятна, заломы, неравномерность печати — включается тумблером с ползунком интенсивности (0 = чистый лист, 100 = сильно потрёпанный вид).
- Лёгкий шум/зерно, имитирующий печать или скан, как отдельная опция.

### 4.7 Экспорт
- Экспорт готового выпуска в PDF (все страницы выпуска, пригодно для печати).
- Экспорт отдельной полосы или всего выпуска в PNG (для отправки в чат/дискорд).
- Настройка разрешения экспорта PNG.

### 4.8 Хранение проекта
- Проект выпуска сохраняется как JSON-файл (метаданные издания + список блоков/статей + ссылки на изображения в подпапке проекта), позволяя открыть и продолжить редактирование позже.

## 5. Нефункциональные требования
- Полностью офлайн, без сетевых зависимостей в рантайме.
- Разумная скорость обновления превью при правке текста (не должно ощутимо тормозить на выпуске из 5–10 статей).
- Понятный UI, рассчитанный на не-технического пользователя (мастера/игрока), без необходимости трогать файлы вручную.

## 6. Этапы разработки (предложение)

**MVP:**
- Один шаблон полосы (например, шапка + 3 колонки), один встроенный стиль оформления, ручной ввод текста, базовое перетекание по колонкам, экспорт в PDF и PNG без эффектов старения.

**v2:**
- Несколько шаблонов сетки и стилей оформления, вставка изображений, буквица, врезки/цитаты, многостраничные выпуски.

**v3:**
- Эффект состаривания бумаги, библиотека пресетов, сохранение/переиспользование изданий, доп. модули (объявления, погода и т.п.), точная настройка типографики вручную.

## 7. Открытые вопросы для уточнения в процессе разработки
- Финальный выбор архитектуры рендеринга полосы (см. раздел 2) — HTML/CSS-движок под капотом или прямой рендер на Flet.
- Точный список встроенных шрифтов (нужно проверить лицензии для распространения вместе с приложением).
- Нужна ли поддержка кириллицы/других языков в декоративных шрифтах — уточнить при выборе гарнитур.
